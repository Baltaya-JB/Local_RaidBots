# Raidbots local

Application Windows pour simuler ton personnage World of Warcraft avec **SimulationCraft**, directement sur ton PC, avec une interface inspirée de Raidbots.

*by Baltaya*

## Installation

1. Va dans **[Releases](https://github.com/Baltaya-JB/Local_RaidBots/releases/latest)** et télécharge `Local_RaidBots-vX.Y.Z-win64.zip`.
2. Dézippe-le où tu veux (Bureau, Documents…).
3. Lance `Raidbots-win32-x64\Raidbots.exe`.
   - Au premier lancement, **SimulationCraft est téléchargé automatiquement** (bandeau en haut de la fenêtre). Les simulations sont possibles dès la fin.
   - Windows peut afficher « Windows a protégé votre ordinateur » : clique **Informations complémentaires**, puis **Exécuter quand même** (l'application n'est pas signée).

## Utilisation

En jeu, tape `/simc` (addon [SimulationCraft](https://www.curseforge.com/wow/addons/simulationcraft)) et copie le texte (Ctrl+C) : l'application le récupère toute seule.

Outils : Top Gear, Droptimizer, Trinketmaxxing, Améliorations (priorité par écusson), Quick Sim, Stat Weights, Advanced.

## Mises à jour

- **Application** : quand une nouvelle version sort, un bouton **MISE À JOUR** apparaît en haut de la fenêtre. Un clic, et l'application se met à jour et redémarre.
- **SimulationCraft** et **données du jeu** : mises à jour automatiques (réglables dans Options).

## Tes données

Tout reste sur ton PC, dans `%APPDATA%\Raidbots local` : personnages enregistrés, historique, réglages. Rien n'est envoyé ailleurs. Pour tout remettre à zéro, ferme l'application et supprime ce dossier.
